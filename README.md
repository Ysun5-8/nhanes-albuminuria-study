# NHANES albuminuria harmonisation

This study examines how CDC urine albumin assay harmonisation changes
single-specimen UACR classification in US adults aged 20 years and over.
The primary sample is NHANES August 2021–August 2023; January 2017–March 2020
provides a reference-cycle feasibility audit. This is an assay-scale comparison,
not a clinical diagnosis of chronic kidney disease (CKD).

## Project report

The report covers the paired survey analysis, sensitivity checks and an exploratory
ML extension examining how the assay definition affects model evaluation. SQL
(SQLite) prepares the data; Python performs survey estimation and modelling; R
checks the survey analysis through a separate implementation and produces the figures. The assay
conversion equation is treated as fixed.

## Reproduction

Use the project Python environment from the repository root. The command below
runs the core tests; eight optional ML tests are skipped when scikit-learn is
not available on the module search path. The ML launcher below loads the optional
packages and runs all 32 tests:

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

After reviewing which outputs will be replaced, the analysis sequence is:

```powershell
.\.venv\Scripts\python.exe -B -m scripts.sql_pipeline
.\.venv\Scripts\python.exe -B -m scripts.pilot.audit_cohort
.\.venv\Scripts\python.exe -B -m scripts.pilot.check_feasibility
.\.venv\Scripts\python.exe -B -m scripts.paired_analysis
.\.venv\Scripts\python.exe -B -m scripts.validation.check_sql_integration
.\scripts\validation\run_validation.ps1 -ReviewRobustness
```

**These analysis commands replace named aggregate outputs and generated reports.**
The robustness command also reruns independent validation. Use a separate review
root to preserve an existing run. Missing raw files may be downloaded by the
Python loader; existing XPT files are not replaced.

The launcher finds R through an optional repository-local installation, PATH or
the Windows R installation registry. Its script and library paths are resolved
relative to the repository. See the [reproduction guide](docs/reproduction.md)
for Python 3.12.10, R 4.6.1, exact package versions, all four CDC downloads and
portable path overrides. Local `.tools/` and `.r-library/` folders are ignored
by Git. No package installation is performed by the launcher.

The ML extension uses additional local packages and four predictor files. After
the setup in [ML reproduction](docs/ml_reproduction.md), run:

```powershell
.\scripts\ml\run_ml.ps1 -Test
.\scripts\ml\run_ml.ps1
.\scripts\ml\run_ml.ps1 -Validation
Rscript scripts/visualisation/create_research_figures.R .
Rscript scripts/visualisation/create_ml_calibration.R .
```

Both figure commands accept the repository root as their argument. Use the full
path to Rscript if it is not on PATH. The ML commands replace their named
aggregate tables and reports. Raw data and local package folders remain excluded
from Git.

## Interpretation

Unweighted counts describe the observed sample. Survey-weighted estimates use
MEC weights, strata and PSUs. Their intervals describe survey-sampling uncertainty
under the stated assumptions; they do not include assay-bridge uncertainty or
eliminate missing-data bias. The plan followed an exploratory pilot and was not
prospectively preregistered.

ML results describe internal validation of single-specimen UACR classification.
Split ranges are not confidence intervals; resampling intervals condition on
fixed predictions and exclude model-refitting uncertainty. No fitted clinical
model, external validation or future-disease forecast is provided.
